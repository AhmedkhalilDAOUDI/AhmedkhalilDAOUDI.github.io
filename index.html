01 / Knowledge systems

CRAG

A document question-answering project that combines a knowledge graph with semantic and keyword search.

  • Ingests PDFs and other document formats, including OCR for scanned pages.
  • Links answers to retrieved passages and graph facts; citation checks confirm that quoted text appears in the source.
  • Compares graph-assisted retrieval with classic RAG modes in a small academic evaluation.

02 / Applied ML

Fraud Detection

A credit card fraud classifier built for a highly imbalanced public benchmark dataset.

  • Compared 13 algorithms and used SMOTE only on the training data.
  • The project reports 0.8808 PR-AUC for its final Extra Trees model on the held-out set.
  • Includes an interactive Streamlit interface for exploring predictions.

03 / Data engineering

Spotify Pipeline

An end-to-end pipeline for exploring personal listening patterns.

  • Extracts recently played and top tracks from the Spotify API.
  • Stores raw data as Parquet, transforms it with Pandas, and loads it into PostgreSQL.
  • Includes scheduled runs and a notebook for listening-pattern analysis.
